# Lyrcing for Windows

지금 듣는 노래의 가사를 박자에 맞춰 화면으로 그려 주는 Windows 가사 비주얼라이저입니다.
Spotify, YouTube Music, 멜론 등 어떤 플레이어로 듣든 Windows의 "지금 재생 중" 정보를 읽어 따라갑니다.

이 저장소는 설치 파일 배포용입니다.

## 내려받기

**[Lyrcing-setup.exe (최신 버전)](https://github.com/OnePaperHoon/lyrcing-releases/releases/latest/download/Lyrcing-setup.exe)**

- Windows 10 / 11 (x64)
- 코드 서명이 없는 설치 파일이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜹니다. **추가 정보 → 실행**을 누르면 설치됩니다.
- 버전별 변경 사항은 [Releases](https://github.com/OnePaperHoon/lyrcing-releases/releases)에 있습니다.

## 출처와 라이선스

macOS 앱 [Lyrcing](https://github.com/yuvraj0011/lyrcing)(Yuvraj Pandey)을 기반으로 한 Windows 포트입니다. MIT 라이선스를 따릅니다 ([LICENSE](LICENSE)).
